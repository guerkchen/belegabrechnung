# Frontend für die Belegabrechnung

Dieses Frontend ist als responsives Bootstrap-HTML-Prototype aufgebaut und enthält:

- eine Navigationsleiste
- die Screens Home, Beleg einreichen, Meine Belege
- rollenabhängige Screens für Freigeber und Kassenwart
- eine Fußzeile mit Impressum und Datenschutz

## Nutzung

Öffne die Datei [frontend/index.html](frontend/index.html) in einem Browser.
